## О чём игра

Мёртвая планета, пустое поле и набор семян. Ты строишь автоматизированную фабрику: растения превращаются в блюда, блюда в монеты, монеты в новые машины. Всё живёт на **одном общем поле**, где машины соединяются проводами, как в Factorio, но рассчитано на короткие сессии с телефона.

## Как это работает

```
Колодец ──вода──▶ Грядки ──плоды──▶ Смеситель ──смесь──▶ Печь ──блюда──▶ Рынок ──▶ монеты
                                        ▲                  ▲                └──▶ Лаборатория ──▶ наука
Генератор ───────────энергия────────────┴──────────────────┘
```

- **Провода по цвету ресурса.** Вода, энергия, плоды и блюда не смешиваются: соединить можно только выход со входом того же цвета.
- **Диагностика.** Если у машины есть неподключённый вход, она подсвечивается оранжевым «!».
- **Доход зависит от схемы.** Монеты идут, только пока рынок подключён к печи. Наука идёт от подключённой лаборатории. Отключил провод, и поток встал.
- **Работает офлайн.** Пока вы не в игре, фабрика продолжает производить.

## Экраны

| Экран | Что делает |
| --- | --- |
| Поле | Граф машин. Двигай поле и машины, тяни провода |
| Каталог | Покупка новых машин за монеты |
| Наука | Дерево исследований: открывает новые возможности |
| Заказы | Гости с капризами, награды и цены рынка |
| База | Поселение, жители и улучшения |

## Управление

- Тяни **пустое поле**, чтобы двигаться по карте.
- Тяни **машину**, чтобы переставить её. Провода перестроятся сами.
- Тяни от **выхода** (круг справа) ко **входу** (квадрат слева) того же цвета, чтобы проложить провод.
- Тапни по **занятому входу**, чтобы убрать провод.
- Тапни по машине, чтобы подсветить только её связи.

## Запуск

Игра не требует сборки: это статические файлы.

```bash
git clone https://github.com/screpka228/cosmic-garden.git
cd cosmic-garden
python3 -m http.server 8080
```

Открой `http://localhost:8080`. На телефоне игру можно добавить на экран «Домой» как приложение.
